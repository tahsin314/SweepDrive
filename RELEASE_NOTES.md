# SweepDrive v1.0

First public release of **SweepDrive** — a free, portable Windows disk cleaner.

## Highlights
- **One-click Safe Clean** — clears caches & temp only; keeps your files, logins and settings.
- **Windows junk, browser, developer, and GPU shader caches** in tidy tabs.
- **Downloads analyzer** with safe delete to the Recycle Bin (recoverable).
- **Advanced (admin):** Windows Temp, Windows Update leftovers, Delivery Optimization,
  logs, memory dumps, Prefetch, WinSxS/DISM cleanup, and WSL2 disk compaction.
- **Single `.exe`** — no installer, no admin required, runs from anywhere.

## Install
Download `SweepDrive.exe` below and double-click. On first run, Windows SmartScreen
may warn (the app is unsigned) — click **More info → Run anyway**.

For the Advanced tab, right-click the exe → **Run as administrator**, or use the
in-app **Restart as Admin** button.

## Notes
- Requires Windows 10/11 (.NET Framework 4.x, preinstalled).
- Everything is shown before deletion; use at your own risk and keep backups of anything important.
